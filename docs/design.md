# Design

Light "cinematic editorial" theme.

- Pure white (`#FFFFFF`) page background with near-black (`#111111` ≈ `hsl(0 0% 7%)`) page-level text (logo wordmark, headings, stat numbers, filter buttons). Warm gold accent (`#E8B500` ≈ `hsl(46 100% 45%)`) is kept as `--primary`/`--accent`/`--ring` for the gold star ratings, the logo film/brand icon, the `+` FAB, and other small accents — gold is an ACCENT only, never large text on white (gold-on-white fails contrast). Logo wordmarks are `text-foreground` (black) with a `text-primary` (gold) icon.
- Fonts (loaded in `index.html` + `index.css`): `Bebas Neue` as the display font (`--font-serif`, used for all headings/logo via the base `h1–h6` rule — set in uppercase with wide tracking for a movie-poster feel); `Oswald` as body (`--font-sans`).
- `:root` and `.dark` tokens are kept IDENTICAL (both hold the LIGHT palette) and `<html class="dark">` is still set (so Clerk's shadcn theme + any `dark:` utilities stay consistent). Editing the palette means editing BOTH blocks in `index.css`. Clerk's own `appearance.variables` in `App.tsx` are an independent light palette.
- Show cards are a NAVY gradient surface (`#1E3A5F → #142841`) via `.poster-card`, which ALSO re-scopes the design tokens locally (`--foreground`/`--card-foreground` → white, `--muted-foreground` → light cool gray, `--background`/`--muted`/`--border`/`--input` → navy tones, `--badge-outline`/`--button-outline` → translucent white). This means every card-internal element that uses token-based utilities (`text-foreground`, `text-muted-foreground`, `bg-background`, `border-border`, badges, the Save button, AudienceSummary, dividers) automatically renders readable light-on-navy with NO per-component overrides. To restyle card internals, prefer adjusting the scoped tokens on `.poster-card` over editing each card.
- `.cinematic-panel` is a subtle light gradient (`hsl(0 0% 97%) → background`) for page hero sections; hero stat sub-cards use `bg-black/[0.03]` + `border-black/10` (faint on white). Avoid large `bg-primary` (gold) fills as backgrounds.
